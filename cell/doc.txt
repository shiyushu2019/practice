
（一）研究目的 本项目旨在针对传统血细胞检测中人工显微镜计数效率低、主观性强及易疲劳等临床痛点，开展基于改进型深度学习算法的血细胞智能检测研究，旨在构建一套高效、精准且具备临床应用潜力的自动化辅助诊断系统。 1. 算法层面的深度优化与突破 本项目的核心目的在于解决现有检测模型在面对血细胞粘连、重叠以及红白细胞类别极度失衡时的检测难题。我们将以 YOLOv8 算法为基础，构建 CF-YOLOv8 改进模型。通过引入 CBAM 注意力机制，增强模型对细胞核及边缘纹理等关键特征的提取能力，解决复杂背景下细胞粘连导致的漏检误检问题；同时，引入 Focal Loss 损失函数替代传统交叉熵损失，有效缓解红细胞（易分样本）与白细胞（难分样本）数量长尾分布带来的检测偏向性，显著提升少数类别的识别精度。**【补充：此外，引入 DAMS-Net（动态自适应多尺度特征融合网络），通过动态调整多尺度特征融合权重，根据输入图像内容自适应增强浅层细节特征与深层语义信息，解决小目标密集与细胞严重粘连场景下的检测精度问题。】** 2. 系统层面的工程化落地 项目致力于实现从 "算法模型" 到 "实用工具" 的转化。我们将开发集图像上传、自动检测、结果可视化及报告生成于一体的智能检测演示系统。**【补充：系统支持三种检测模式——实时摄像头检测、单图上传检测与 Web 端在线检测；实时摄像头模式下需设置置信度阈值、关闭逐帧日志输出以降低计算开销，并配置底层计算库兼容性（避免多线程数值计算库重复加载冲突），推理结束后自动释放摄像头资源。系统同时输出各类细胞的统计计数结果。】** 同时，针对基层医疗设备算力有限的现状，开展模型轻量化研究（如剪枝、量化），确保优化后的模型在保持高精度（目标精确率 > 90%， mAP@0.5 >0.95）的同时，具备在嵌入式设备（如 Jetson Nano）上实时运行的能力（30 FPS），满足临床快速筛查的需求。**【补充：轻量化具体采用 INT8 量化加通道剪枝的组合方案，并通过知识蒸馏恢复精度。】** 3. 临床应用与社会价值 最终，本项目旨在通过构建标准化、自动化的血细胞检测方案，大幅减轻检验医师的工作负担，降低人为误差，为贫血、感染及白血病等疾病的早期筛查提供客观、可靠的数据支持。这不仅有助于推动智慧医疗在基层的普及，更具有显著的社会效益和广阔的市场应用前景。

（二）研究内容 本项目聚焦 CF-YOLOv8 血细胞检测模型的优化与应用，针对血细胞形态多样、易粘连、类别失衡等问题，开展五项核心研究，层层递进，目标明确： 1. 模型深度优化 在 CF-YOLOv8 基础上，优化 CBAM 注意力机制的结构与嵌入位置，调优 Focal Loss 超参数，引入多尺度特征融合，提升对小目标和粘连细胞的检测精度，增强模型性能。**【补充：多尺度特征融合具体通过 DAMS-Net 模块实现，需单独编码该模块并完成消融实验验证；Focal Loss 仅替换分类分支损失，边界框回归损失与 DFL 损失保持不变。】** 2. 数据集构建与验证 拟与医院检验科合作，采集多类临床血液图像，弥补公开数据集的不足；完成图像预处理与标注，构建临床验证集，评估模型在真实场景中的泛化能力。**【补充：BCCD 数据集原始标注为 VOC 格式，需编写数据转换程序将其统一转换为 YOLO 格式；标注工具使用 LabelImg，并建立双人标注加专家复核的内部复核机制。】** 3. 可视化系统开发 基于 PyQt 或 Flask 开发检测演示系统，实现图像上传、自动检测、结果标注与报告生成，界面简洁友好，推动模型向实用化工具转化。**【补充：系统需实现三条独立代码路径——实时摄像头检测（OpenCV 逐帧采集+推理+实时预览窗口）、单图上传检测（离线分析）、Web 端在线检测；输出内容包含检测框、类别标签、置信度及各类细胞统计计数。后续将推理代码封装为 SDK 包，提供 API 接口（输入图片→输出检测框、类别、置信度、细胞计数）。】** 4. 模型轻量化研究 采用剪枝、知识蒸馏和量化等技术，在保持高精度的前提下压缩模型体积、提升推理速度，为嵌入式部署提供支持。 5. 模型评估与迭代优化 通过消融实验与对比分析，系统评估各改进模块的贡献；结合校内试用与用户反馈，持续优化模型性能与系统交互体验，完善技术方案，提升系统的稳定性与实用性。**【补充：消融实验设计五个实验组——基准 YOLOv8、+Focal Loss、+CBAM、+DAMS-Net、CF-YOLOv8；对比实验涵盖 YOLOv4、YOLOv5、YOLOv6、YOLOv7、YOLOv8 五个基线模型；评估指标需按 RBC、WBC、ALL 三个维度分别输出 Precision、Recall、mAP@0.5。】**

（三）国、内外研究现状和发展动态 在国外，血细胞检测研究经历了从传统图像处理到深度学习的演进。早期采用阈值分割、分水岭等图像处理方法，后发展为基于 SVM 等机器学习的特征工程方法。近年来，深度学习技术成为主流，卷积神经网络（CNN）在细胞分割与分类任务中表现优异，YOLO 系列算法因其检测速度快、准确率高而广泛应用。目前研究趋势正向多模态融合、无染色成像和实时动态监测方向发展，Transformer 架构和视觉语言模型也开始被探索应用于血细胞分析。 在国内，血细胞检测研究热度持续上升。早期多基于传统图像处理和机器学习方法，近年深度学习技术成为研究主流。基于 YOLOv5、YOLOv7 等算法的血细胞检测方法不断涌现，融合注意力机制（CBAM、ECA 等）、优化损失函数（Focal Loss 等）、改进特征金字塔结构成为研究热点。国内学者在注意力机制融合、模型轻量化、小目标检测等方面取得积极进展，检测精度和效率持续提升。

（四）创新点与项目特色 ①算法结构创新 在 YOLOv8 的 ConvModule 中嵌入 CBAM 注意力模块，通过通道与空间双重机制引导模型聚焦细胞核、边缘纹理等关键区域，抑制背景噪声，解决细胞粘连、重叠及尺度差异导致的漏检误检问题，提升复杂场景特征提取能力。**【补充：CBAM 模块置于 Conv2d 卷积层之后、BN 归一化层之前；通道注意力使用最大池化与平均池化共享 MLP（1 输入层、3 隐藏层、1 输出层，元素求和后经 sigmoid），空间注意力使用 7×7 卷积核。】** ②损失函数优化 针对血细胞长尾分布问题，引入 Focal Loss 替代传统交叉熵损失，降低易分类红细胞样本权重，引导模型重点学习难分类的白细胞，缓解检测偏向性，显著提升少数类别的识别效果与检测均衡性。**【补充：Focal Loss 公式为 FL(pt) = -α(1-pt)^γ log(pt)，配置 α=0.25、γ=2.0；仅作用于分类分支损失，需修改前向传播和反向传播代码使损失计算适配模型输出。】** **【补充：③多尺度动态融合创新 引入 DAMS-Net 动态自适应多尺度特征融合网络，替代传统特征金字塔固定权重融合，根据输入图像内容自适应调整多尺度特征融合权重，在小目标密集、细胞严重粘连场景下提升检测精度，全局 mAP@0.5 从 0.944 提升至 0.953，仅以 3 FPS 代价实现精度与效率平衡。】** ③模型性能优异 改进后的 CF-YOLOv8 在 BCCD 数据集上精确率达 89.7%、 mAP@0.5 达 0.947，优于 YOLOv5 等主流模型；同时保持 30 FPS 实时检测速度，在提升精度的同时契合临床快速筛查需求，实现精度与效率双重优化。 ④落地路径清晰 项目以临床落地为导向，后续将采集多样本验证泛化能力；同时开发可视化检测系统，集成图像上传、自动检测、报告生成等功能。预留轻量化路径，通过剪枝、蒸馏等技术适配 Jetson Nano 等嵌入式设备，助力基层医疗与现场快速检测。**【补充：落地交付物包含模型权重文件、SDK 开发包（提供 API 接口）、桌面客户端软件及技术文档；SDK 支持输入血液显微图片，输出检测框、细胞类别、置信度、细胞统计计数结果。】**

（五）技术路线、拟解决的问题及预期成果 技术路线 （1）数据收集与预处理 ①以公开 BCCD 数据集为基础，尝试拓展临床图像来源，采集不同病理状态临床图像，保障数据多样性与临床代表性。**【补充：BCCD 数据集包含 364 张标注血细胞图像，涵盖红细胞（RBC）、白细胞（WBC）两个类别。】** ②采用公开的临床显微镜标准图像，在统一分辨率与格式下进行整理，严格实施数据脱敏，兼顾图像质量与隐私安全。 ③使用 LabelImg 工具，在系统学习基础医学形态学知识的基础上进行精准标注，并建立严格的内部复核机制，确保标注结果符合临床检测要求。**【补充：BCCD 原始标注为 VOC 格式，需编写转换脚本统一转为 YOLO 格式（归一化中心点坐标+宽高），方可输入模型训练。】** ④组合中值与高斯滤波去噪，通过直方图均衡化改善染色不均，统一调整图像尺寸为 640×640，适配网络输入。 ⑤实施随机旋转、翻转、色彩调整及 Mosaic 增强，扩充训练集规模，提升模型泛化能力。**【补充：数据增强还包括 HSV 色彩扰动与随机裁剪，模拟显微镜成像差异。】** ⑥按 8:2 比例划分训练集与测试集，从训练集中抽取 20% 作为验证集，用于超参数调优与性能评估。 （2）模型构建与改进实施 本项目所有代码基于 Python 和 PyTorch 1.9 深度学习框架编写，涵盖训练、推理、评估和部署环节。**【补充：实验硬件环境为 Intel Core i7-9700K 处理器、NVIDIA GeForce RTX 3080 显卡、Windows 11 操作系统。】** ①搭建 YOLOv8n 基准模型，加载 COCO 预训练权重，采用迁移学习策略初始化网络参数。 ②在 Backbone 的 ConvModule 中嵌入 CBAM 注意力模块，强化通道与空间特征表达，提升粘连细胞识别率。具体地，CBAM 模块置于 Conv2d 卷积层之后、BN 归一化层之前，包含通道注意力和空间注意力串联计算，其中通道注意力使用最大池化与平均池化共享 MLP，空间注意力使用 7×7 卷积核。 ③替换分类损失函数为 Focal Loss，配置 α=0.25、γ=2.0 参数，降低易分样本权重，缓解类别不平衡。同时，需修改前向传播和反向传播代码，使损失计算适配模型输出。**【补充：Focal Loss 仅替换分类分支（cls loss），边界框回归损失（box loss）与分布焦点损失（dfl loss）保持不变。】** **【补充：③+ 引入 DAMS-Net 动态自适应多尺度特征融合模块，替换 Neck 部分传统特征金字塔的固定权重融合，根据输入图像内容动态调整多尺度特征融合权重，需单独编码该模块并在消融实验中验证其贡献。】** ④采用 SGD 优化器训练 100 轮，结合余弦函数衰减规律调整学习率，自动保存最优 mAP 模型。（本项目实际采用 Adam 优化器，初始学习率设为 0.001，batch size 为 16，并设置早停策略（patience 为 10 个 epoch），训练过程中记录训练 loss 和验证集指标，并自动保存验证集 mAP 最优的模型权重。） ⑤通过消融实验验证改进效果，CF-YOLOv8 在 BCCD 数据集上评估指标达 94.7%，性能优于主流检测模型。具体评估指标包括精确率（Precision）、召回率（Recall）、 mAP@0.5 （IoU 阈值 0.5）以及推理速度（FPS≥30），同时绘制混淆矩阵、PR 曲线和检测结果可视化图（在图像上画出检测框、类别标签和置信度）。**【补充：消融实验设五个实验组——基准 YOLOv8、+Focal Loss、+CBAM、+DAMS-Net、CF-YOLOv8；对比实验涵盖 YOLOv4、YOLOv5、YOLOv6、YOLOv7、YOLOv8；所有指标需按 RBC、WBC、ALL 三类分别输出。混淆矩阵需包含 RBC、WBC、background 三类。】** （3）迁移学习流程执行 ①选用 COCO 预训练的 YOLOv8n 权重，迁移通用图像特征，提升模型泛化能力。 ②基于 BCCD 公开血细胞图像数据，进行格式统一与标注标准化，采用数据增强技术模拟成像差异，增强提升数据多样性。 ③先冻结主干训练检测头，再解冻全网低学习率精调，兼顾通用与医学特征。 ④引入 Focal Loss 缓解类别不平衡，配合余弦退火学习率与 SGD/AdamW 优化器，稳定收敛。 ⑤对比从头训练，监控验证指标并启用早停，防止过拟合，确保模型最优性能。 （4）模型训练与优化迭代 ①采用 YOLOv8n 为基线，加载 COCO 预训练权重，利用迁移学习初始化参数，避免随机初始化导致的震荡，为后续血细胞特征学习奠定基础。 ②嵌入 CBAM 模块增强细胞特征提取，替换 Focal Loss 缓解红白细胞类别不平衡，通过消融实验验证双改进策略有效提升模型精度。**【补充：消融实验还需验证 DAMS-Net 模块的独立贡献。】** ③先适配检测头，后低学习率微调全层，兼顾通用特征与医学特异性，防止过拟合。 ④结合 Mosaic、HSV 扰动及旋转翻转策略，模拟显微镜成像差异，扩充样本多样性，提升模型在复杂临床环境下的鲁棒性。 ⑤动态调整学习率与 Batch size，结合余弦退火策略；监控 mAP@0.5 与 Loss 指标，启用早停机制，保存最优模型权重。 拟解决的问题 1. 传统检测手段效率低且主观性强 传统的血细胞检测主要依赖人工显微镜观察和手工分类。这种方法不仅耗时费力，而且检测结果高度依赖操作者的经验。容易因为视觉疲劳导致主观性强、准确性与一致性差，难以满足现代临床快速诊断的需求。 2. 现有模型（YOLOv8）对 "粘连与重叠" 细胞的检测能力不足 血液细胞在显微镜下常出现粘连、重叠的现象，且细胞形态多样。传统的 YOLOv8 算法感受野有限，难以捕捉细胞的细节和局部特征。这导致模型在面对重叠细胞时，容易出现漏检（没看到）或误检（看错），无法精确识别和定位相互接触的细胞。 3. 数据类别极度 "长尾分布" 导致的检测偏向 在血液样本中，红细胞（RBC）的数量远远多于白细胞（WBC）。传统的交叉熵损失函数在训练时，会被数量庞大的红细胞样本主导。这导致模型倾向于识别 "好分" 的红细胞，而忽视难分的少数类样本（白细胞），造成类别不平衡问题，降低了对白细胞的检测精度。 4. 小目标与多尺度特征提取困难 血细胞图像中，细胞的尺寸差异大，且存在密集分布的情况。现有模型（包括原始 YOLOv8）的特征金字塔结构对多尺度特征的融合权重往往是固定的，难以动态适应复杂场景（如细胞严重粘连或染色不均），导致对微小或尺寸异常的细胞检测效果不佳。**【补充：该问题通过 DAMS-Net 动态自适应多尺度特征融合网络解决，根据输入图像内容自适应增强浅层细节特征和深层语义信息。】** 预期成果 1. 专利 1 篇。 2. 实验模型及算法的论文 2-3 篇。**【补充：代码交付物还包括 CF-YOLOv8 模型权重文件、VOC→YOLO 格式转换脚本、可视化检测系统（含实时摄像头/单图/Web 三种模式）、SDK 开发包及 API 接口文档。】**
