## Web 检测系统 (app.py)

CLI 启动：
  python app.py                                 # 默认端口 5000
  python app.py --port 8080                     # 指定端口
  python app.py --device 6 --conf 0.3           # 指定 GPU 与置信度阈值
  python app.py --weights weights/cbam.pt --device 0

参数：
  --host      监听地址（默认 0.0.0.0）
  --port      端口（默认 5000）
  --device    GPU 编号（0-7 或 cpu；默认 0 号显卡）
  --weights   模型权重路径（默认 weights/cf.pt）
  --conf      置信度阈值（默认 0.25）
  --debug     开启 Flask 调试模式（默认关闭）
环境变量：CELL_HOST / CELL_PORT / CELL_DEVICE / CELL_WEIGHTS / CELL_CONF 可覆盖上述参数。

启动后浏览器打开 http://127.0.0.1:5000 即可使用。
网页内（左下角“设置”面板）支持：查看/切换权重、查看/切换推理设备（GPU/CPU，实时显示空闲显存）、
调整置信度阈值、查看/搜索/回放/清空检测历史记录。


## 摄像头实时检测 (camera.py)

环境：python（先激活 conda 环境，在 cell 目录下执行，需在有摄像头与显示器的机器上运行）

# 默认摄像头 0 + weights/cf.pt，实时检测并按 q 退出
python camera.py

说明：程序打开摄像头 0，加载 weights/cf.pt，以置信度 0.25 逐帧检测并绘制检测框，按 q 退出。
（camera.py 无命令行参数，摄像头编号、权重、置信度均为内置值。）


## 训练 / 推理 / 验证 (train.py / inf.py / eval.py)

Python 环境：python（先激活 conda 环境，在 cell 目录下执行）

--------------------------------------------------------------------------------
train.py —— 训练脚本（--variant 可选 baseline/cbam/cf）
--------------------------------------------------------------------------------

基本用法：
  python train.py --variant cf --device 0 --epochs 100 --batch 32
  python train.py --variant baseline --device 0                 # 纯 YOLOv8n 对照
  python train.py --variant cbam --device 0                     # YOLOv8n + CBAM
  python train.py --variant cf --dataset bccd --device 0        # 仅 BCCD 数据集
  python train.py --variant cf --dataset txl --device 0         # 仅 TXL-PBC 数据集
  python train.py --variant cf --freeze-epochs 10 --device 0    # 迁移学习：先冻结后解冻
  python train.py --variant cf --out cf_v2 --device 0           # 输出 weights/cf_v2.pt

完整参数（默认值见括号）：
  --variant         变体 baseline/cbam/cf（默认 cf）
  --device          GPU 编号（默认 0；也可 0-7 或 cpu）
  --epochs          训练轮数（默认 100）
  --batch           Batch size（默认 32）
  --gamma           Focal Loss γ（默认 1.5）
  --alpha           Focal Loss α（默认 0.25）
  --normalize       Focal Loss 按 BCE 总量归一化（默认开启；--no-normalize 关闭）
  --freeze-epochs   冻结主干训练检测头的轮数（默认 0，即不冻结；文档迁移学习为 10）
  --unfreeze-lr     解冻后精调阶段学习率（默认 0.005）
  --out             输出权重文件名（默认 weights/<variant>.pt）
  --dataset         数据集 bccd/txl/mixed（默认 mixed）
  --data            数据集 yaml 路径（指定后覆盖 --dataset）
  --imgsz           输入图像尺寸（默认 640）
  --optimizer       优化器 SGD/Adam/AdamW/...（默认 SGD）
  --lr0             初始学习率（默认 0.01）
  --lrf             最终学习率系数 = lrf*lr0（默认 0.01）
  --weight-decay    权重衰减（默认 0.0005）
  --warmup-epochs   warmup 轮数（默认 3）
  --no-cos-lr       关闭余弦学习率退火
  --mosaic          Mosaic 增强概率，0 关闭（默认 1.0）
  --close-mosaic    最后 N 轮关闭 Mosaic（默认 10）
  --degrees         随机旋转角度范围（默认 180）
  --flipud          上下翻转概率（默认 0.5）
  --fliplr          左右翻转概率（默认 0.5）
  --hsv-h           HSV-H 扰动（默认 0.015）
  --hsv-s           HSV-S 扰动（默认 0.7）
  --hsv-v           HSV-V 扰动（默认 0.4）
  --patience        早停耐心轮数（默认 100）
  --seed            随机种子（默认 0）
  --no-deterministic 关闭确定性训练
  --no-amp          关闭混合精度 AMP
  --no-plots        不保存训练曲线图

训练完成后 best 权重统一保存到 weights/<variant>.pt（或 --out 指定的文件）。

--------------------------------------------------------------------------------
inf.py —— 推理脚本（单图或目录）
--------------------------------------------------------------------------------

基本用法：
  python inf.py --source a.jpg                                  # 单图
  python inf.py --source dataset/BCCD_Dataset/test/images       # 目录
  python inf.py --dataset mixed                                 # 不传 --source，自动用混合测试集
  python inf.py --dataset bccd --weights weights/cf.pt --conf 0.3 --save
  python inf.py --source a.jpg --imgsz 640 --iou 0.7 --max-det 300 --save-txt --save-conf

完整参数（默认值见括号）：
  --source      图片路径或目录（未指定时用 --dataset 对应的测试集）
  --dataset     数据集 bccd/txl/mixed（默认 mixed，仅用于默认测试图目录）
  --weights     权重路径（默认 weights/cf.pt）
  --conf        置信度阈值（默认 0.25，越界自动夹取到 0.01-1.0）
  --imgsz       推理输入尺寸（默认 640）
  --iou         NMS IoU 阈值（默认 0.7，越界自动夹取到 0-1）
  --max-det     每张图最大检测框数（默认 300，至少 1）
  --device      GPU 编号（默认 0；也可 0-7 或 cpu）
  --save        保存带检测框的结果图到 temp/results/
  --save-txt    保存 YOLO 标签 txt
  --save-conf   标签 txt 附带置信度

说明：标注结果图（--save）输出到 cell/temp/results/；--save-txt 的标签文件由
ultralytics 按自身规则生成（通常为 runs/detect/predict* 或源目录下），与结果图路径不同。

--------------------------------------------------------------------------------
eval.py —— 验证脚本（测试集/验证集）
--------------------------------------------------------------------------------

基本用法：
  python eval.py                          # 默认测试集、0 号卡、混合数据集，评估内置 4 个权重
  python eval.py --split val              # 用验证集
  python eval.py --device 6               # 换卡
  python eval.py --dataset bccd           # 仅 BCCD 数据集
  python eval.py --weights weights/cf.pt,weights/cbam.pt --device 0

完整参数（默认值见括号）：
  --split    评估集 test/val（默认 test）
  --device   GPU 编号（默认 0；也可 0-7 或 cpu）
  --dataset  数据集 bccd/txl/mixed（默认 mixed）
  --data     数据集 yaml 路径（指定后覆盖 --dataset）
  --imgsz    验证输入尺寸（默认 640）
  --iou      验证 NMS 的 IoU 阈值（默认 0.7，越界自动夹取到 0-1）
  --weights  逗号分隔的权重路径；不指定则评估内置 baseline/cbam/cf/cf_norm
